DAZ软件踩坑备忘录 - 问题

问题描述：一直卡加载界面，闪退。

  • 2024年12月17日，启动DAZ软件失败，报错提示：Only one instance of Studio General Release can be running at a time，后过一会儿就会退出软件，搜了一圈，有人说是DAZ没卸载干净，实际上是 log.txt 和 dazstudio.dau 文件的锅。如果删掉整个C盘 Roaming 里面的DAZ 3D文件夹和重装系统都很麻烦，个人设置也没了，所以只需要
  • win+r 输入 %AppData%
  • 定位到你的 DAZ 3D 目录，找到 Studio4 文件夹里面的 log.txt 和 dazstudio.dau 这两个文件，再启动就Ok了
  • C:\Users\你的用户名称\AppData\Roaming\DAZ 3D\Studio4

来自：百度贴吧 21楼回答

关键词：# ExP Exporter己加载. # 闪退 # DAZ # 卡加载界面
